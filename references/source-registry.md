# 五个用户指定来源的使用登记

| 来源 | 类型 | 当前可用状态 | 使用规则 |
|---|---|---|---|
| 北大法宝 | 商业法律数据库 | 需要账号或订阅，自动访问可能超时 | 仅在用户具有合法访问权限并提供导出的案例文件后导入 |
| 中国裁判文书网 | 官方裁判文书平台 | 首页可访问，当前页面提示系统升级维护 | 不绕过维护、验证码或访问控制；保存官方链接和取得时间 |
| 人民法院案例库 | 最高人民法院案例平台 | 公共检索页可访问，页面显示案例总量 | 优先作为指导性、参考性案例来源，保存案例编号和官方PDF/页面链接 |
| 中国审判流程信息公开网 | 审判流程公开平台 | 公开抓取受限，且不是完整裁判文书库 | 不把流程状态当作裁判结果；涉当事人案件仅凭合法授权访问 |
| 威科先行 | 商业法律数据库 | 页面依赖JavaScript，通常需要账号或订阅 | 仅在用户具有合法访问权限并提供导出的案例文件后导入 |

## 采集记录要求

每条资料保存来源、原始网址、取得日期、访问状态、案例编号、原文哈希、法律版本和是否人工复核。商业数据库的检索结果不能在没有授权的情况下批量复制、公开或再分发。
