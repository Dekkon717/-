# 商标侵权分析规则

## 分析顺序

1. 权利是否在被诉行为发生时有效，包括注册、续展、转让和许可状态。
2. 原告是否为权利人，或是否取得足以独立起诉的授权。
3. 被告实施了生产、销售、许诺销售、广告、店招、包装、网络展示、仓储、帮助等何种行为。
4. 被诉标识是否属于商标性使用。
5. 标识是否相同或近似，商品或服务是否相同或类似，是否存在混淆可能性。
6. 合法来源、在先使用、描述性使用、指示性使用、权利用尽、未使用、诉讼时效等抗辩是否成立。
7. 停止侵权、销毁、赔偿、合理开支和其他责任如何确定。

## 决定性事实

### 权利基础

- 商标注册号、权利人、核定商品或服务、有效期。
- 商标在侵权期间是否有效，是否发生转让、续展或无效宣告。
- 被许可人的许可类型、授权期限和起诉权限。
- 原告是否提交实际使用及知名度证据。

### 侵权比对

- 被诉标识的文字、读音、含义、图形、颜色和显著识别部分。
- 标识在商品、包装、店铺、网页、标题、关键词或广告中的具体位置和用途。
- 商品或服务的功能、用途、消费对象、销售渠道和关联程度。
- 相关公众注意程度、商标显著性、知名度和实际混淆证据。

### 合法来源抗辩

分别核对：被告是否属于销售者；是否不知道且不应当知道侵权；是否说明提供者；是否提交合同、订单、付款、物流、发票、聊天记录等形成相互印证的来源链。抗辩成立不当然排除停止销售责任。

### 赔偿

按权利人损失、侵权人获利、许可使用费倍数、惩罚性赔偿、法定赔偿的顺序记录当事人主张和法院实际采用的方法。提取销量、单价、利润率、经营时间、地域、商标声誉、主观恶意、重复侵权、行政处罚、举证妨碍和合理开支。

## 检索词生成

至少生成四组词：

- 案由与行为，如“侵害商标权纠纷 销售 电商平台”。
- 核心判断，如“商标性使用 类似商品 混淆可能性”。
- 抗辩，如“合法来源 进货凭证 不知道”。
- 责任，如“法定赔偿 惩罚性赔偿 举证妨碍”。

检索不应只使用品牌名称；品牌不同但法律问题和决定性事实相同的案件可能更有参考价值。
