# 来源和权威性排序

## 案例顺序

1. 最高人民法院指导性案例。
2. 人民法院案例库参考案例。
3. 最高人民法院典型案例及其生效裁判。
4. 福建省高级人民法院发布的典型、参考案例及生效裁判。
5. 福建上一级法院、本院的普通生效裁判。
6. 其他来源可验证的公开裁判。

等级高不等于事实更相似。报告应分别说明“权威性”和“事实相似度”，不得合并成无法解释的单一结论。

## 来源类型值

数据库 `source_type` 建议使用：

- `guiding_case`
- `people_court_case_library`
- `spc_typical_case`
- `fujian_high_court_typical_case`
- `effective_judgment`
- `other_verified_public_case`

对应 `source_tier` 为 1 至 6，数字越小权威排序越高。

## 核验要求

- 优先使用人民法院案例库、最高人民法院、最高人民法院知识产权法庭、福建省高级人民法院和中国裁判文书网等官方来源。
- 保存原始网址、取得日期、正文哈希和本地原文路径。
- 同一案件的一审、二审、再审分别保存，并通过关联字段说明裁判链条；最终结论以生效裁判为准。
- 网站撤回、更正文书或来源失效时，将案例标记为停用，保留变更记录。
- 普通案例原则上优先近三年；旧案例具有持续参考价值时必须核验法律是否修改。
